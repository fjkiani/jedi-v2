# Schema Content Templates

Templates for filling in Hygraph content. Use these when creating or updating entries to keep content consistent and story-driven.

## Templates

| Template | Model | Use For |
|----------|-------|---------|
| [CATEGORY_SCHEMA_TEMPLATE.md](./CATEGORY_SCHEMA_TEMPLATE.md) | Category | Decision Algorithms, AI Agents, etc. |
| [USECASE_SCHEMA_TEMPLATE.md](./USECASE_SCHEMA_TEMPLATE.md) | UseCase | AI-Powered Research Assistant, etc. |
| [CASESTUDY_SCHEMA_TEMPLATE.md](./CASESTUDY_SCHEMA_TEMPLATE.md) | CaseStudy | Client success stories |

## Usage

1. Open the relevant template
2. Copy the structure into Hygraph fields
3. Replace examples with your content
4. Rich Text fields support markdown in Hygraph
5. JSON fields: use valid JSON format
