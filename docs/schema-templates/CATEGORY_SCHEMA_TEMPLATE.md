# Category Schema Content Template

Use this template when creating or updating Category entries in Hygraph (e.g. Decision Algorithms, AI Agents).

---

## Required Fields

### Name
*Short, descriptive category name*
```
Example: Decision Algorithms
```

### Slug
*URL-friendly identifier (lowercase, hyphens)*
```
Example: decision-algorithms
```

### Description
*1–2 sentence overview*
```
Example: AI-powered systems that automate complex decision-making across business processes.
```

---

## Story Fields

### Tagline
*Short punchy tagline (optional)*
```
Example: Smart decisions at scale
```

### Problem Statement
*What problem does this category solve? Pain points, constraints.*
```markdown
Organizations struggle with:
- Manual decision processes that don't scale
- Inconsistent outcomes across teams
- Lack of audit trails for compliance
```

### Value Proposition
*Why does this category matter? Key benefits.*
```markdown
Decision Algorithms deliver:
- **Consistency** – Same logic applied every time
- **Speed** – Milliseconds vs. hours
- **Auditability** – Full trace of how decisions were made
```

### Typical Use Cases
Leave this blank

### Technology Narrative
*Why these technologies? Fit and rationale*
```markdown
We use rule engines and ML models together: rules for compliance-critical paths, models for high-volume pattern recognition.
```

### Key Outcomes
*Typical results solutions in this category deliver*
Do not write AI SLOP
```
