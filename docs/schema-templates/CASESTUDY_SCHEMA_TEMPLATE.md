# Case Study Schema Content Template

Use this template when creating or updating CaseStudy entries in Hygraph.

---

## Required Fields

### Title
*Case study name*
```
Example: Go Answer Voice AI
```

### Slug
*URL-friendly identifier*
```
Example: go-answer-voice-ai
```

---

## Overview

### Client Name
*Anonymized or actual*
```
Example: Go Answer
```

### Excerpt
*2–3 sentence summary*
```
Example: 24/7 voice AI agents for customer service. 80% faster response times, 60% improved satisfaction.
```

### Description
*Full story – Rich Text*
```markdown
## The Challenge
[Problem description]

## Our Approach
[How JEDI solved it]

## Results
[Metrics and outcomes]
```

### Results
*Key metrics (plain text or bullets)*
```
80% faster response times
60% improved customer satisfaction
95% call resolution accuracy
```
