## How to Use This Audit

1. **Run research** for a topic:  
   `npm run blog:research -- --topic "ai-identity"`
2. **Write** with JEDI-specific examples, real clients, concrete outcomes.
3. **End with “See it in action”** — link to the related application or case study.
4. **Publish** to Hygraph:  
   `npm run blog:create -- --file path/to/post.json`

## Tone Checklist (Avoid AI Slop)

- [ ] Real client names (Go Answer, Clear Mind Life, etc.)—not “a leading enterprise”
- [ ] Concrete numbers (80% faster, 44% no governance)
- [ ] “We” not “organizations”—you built it
- [ ] Questions that hook (“What happens when…?” “Why does…?”)
- [ ] War stories and lessons learned, not generic best practices
- [ ] Related application link—tell *and* show
